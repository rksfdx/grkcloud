Curriculum

Complete Salesforce Technical Curriculum

A structured path from platform fundamentals through development, cloud products, integrations and CPQ.

MODULE 01

Salesforce Platform

Architecture, objects, fields, record types, layouts, App Builder, formulas and validation.

MODULE 02

Security Model

Profiles, permission sets, OWD, roles, sharing, FLS and record-level access.

MODULE 03

Data Model

Relationships, junction objects, external IDs, roll-ups and schema design.

MODULE 04

Data Management

Import Wizard, Data Loader, migration, cleansing, duplicates and data quality.

MODULE 05

Automation

Flow Builder, record-triggered, screen, scheduled, autolaunched flows and debugging.

MODULE 06

Apex Development

SOQL, SOSL, DML, classes, triggers, governor limits, async Apex and testing.

MODULE 07

Lightning Development

Aura fundamentals and LWC architecture, JavaScript, events, wire, Apex and LDS.

MODULE 08

Integrations

REST, SOAP, callouts, Named Credentials, JSON, authentication and error handling.

MODULE 09

Sales Cloud

Leads, accounts, contacts, opportunities, products, price books and sales processes.

MODULE 10

Service Cloud

Cases, queues, Omni-Channel, Knowledge and service automation.

MODULE 11

Experience Cloud

External users, portals, sharing, authentication and Experience Cloud development.

MODULE 12

Salesforce CPQ

Products, configuration, pricing, discounting, quotes and quote line items.
